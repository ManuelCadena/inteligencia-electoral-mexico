II.3Canonical schema — key, outcomes, structural variables

Unique observation key (0 duplicates verified):

key = (AMBITO, CARGO×PRINCIPLE, ANIO, ENTIDAD_CANONICA, GEO_KEY_2, PARTIDO_COALICION, SOURCE_FILE)— grain: election × geography × party

Three variable families:

  • Outcomes: SHARE_TOTAL, SHARE_VALIDO, ES_GANADOR, GANADOR, MARGEN_VICTORIA, NEP (effective number of parties), NUM_PARTIDOS, PARTICIPACION (turnout = votes ÷ lista nominal), TASA_NULOS (null-ballot rate), TASA_NREG (non-registered candidate rate), ALTERNANCIA (party alternation flag). D
  • Structural: ES_PRESIDENCIAL, ES_INTERMEDIA, ES_FEDERAL, ES_LOCAL, AÑO_SEXENIO (year within the six-year term), NIVEL_GEO, FLAG_CONSISTENCIA. D
  • Source context: VOTOS_TOTALES, VOTOS_VALIDOS, LISTA_NOMINAL, ARCHIVO, TERRITORIO (domestic vs abroad ballot). D

No single public series spans 1991–2024: the project will build a harmonized series carrying per-row metadata — pollster, mode, sample, question wording — plus a missingness indicator. P

Each row is one speaker intervention with date, participant, text and word count — i.e., a speaker-attributed, timestamped corpus. Declared gaps: one AMLO day unrecoverable (2024-05-23), and Sheinbaum post-2025-08-22 blocked by the gob.mx WAF (documented, not silently dropped). A legacy lexical-sentiment column inherited from NOSTRODATA is used only as a baseline, flagged as undocumented provenance. D This corpus feeds every lecture in Part IV and the textual channel of the multimodal model (Part V); joining it to the canonical dataset uses the publication date of each conference — never the date of the event discussed — so that no post-election text leaks into pre-election features. Edge cases conditioning the modeling
  • 2012 presidential files split "votes from abroad" vs territory — the pipeline sums both within the same key; TERRITORIO preserves the distinction. D
  • All-NaN trailing rows in some municipal CSVs (Veracruz 2017, Baja California 2019) — dropped. D
  • Coalitions reported alongside their component parties can inflate share sums — modeling decision pending (single actor vs redistribution). P
