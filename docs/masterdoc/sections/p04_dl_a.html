III.1 The Multi-Layer Perceptron — the honest tabular baseline

Neural-network fundamentals: units, activation functions, forward and backward propagation.

Why it exists

An election is, to first approximation, a nonlinear function of tabular features: vote history, marginalization, incumbency, macroeconomics. Before any exotic architecture we need the baseline answering: how much signal lives in the table alone, with no explicit structure?

Theoretical framework

A neuron computes an affine map plus a nonlinearity: y = σ(w·x + b). The Universal Approximation Theorem (Cybenko 1989; Hornik 1991) states that a single hidden layer with enough units approximates any continuous function on a compact set — the existence guarantee; depth is the efficiency story (functions computable with exponentially fewer units deep than wide; Eldan & Shamir 2016). L

Activation functions, expanded: ReLU (Rectified Linear Unit) = max(0, z) — cheap, non-saturating, but can "die" at 0; GELU (Gaussian Error Linear Unit) = x·Φ(x) where Φ is the standard-normal CDF — a smooth probabilistic gating used by Transformers; softmax turns a real vector z ∈ R^K into a probability vector exp(z_i)/Σ_j exp(z_j) lying in the (K−1)-simplex.

h[l] = σ( W[l] h[l−1] + b[l] ),  ŷ = softmax( W[L] h[L−1] + b[L] )

Loss: categorical cross-entropy CE = −Σ_k y_k log ŷ_k measures the divergence between predicted and empirical party-share distributions; it is the MLE objective for a categorical model and the natural metric for our compositional outcome (shares sum to 1). Backpropagation is the chain rule applied layer-wise — computing ∂L/∂W^[l] by propagating δ^[l] = (∂L/∂h^[l]) ⊙ σ′ — enabling gradient descent in O(#params) memory. L

III.2 PyTorch — the reusable experiment harness

Tensors, autograd, Dataset/DataLoader, optimizers, devices.

Why it exists

The pedagogical value is the pipeline, not the framework: a Dataset that materializes the canonical key, a DataLoader yielding election-geography-consistent batches, and a training loop logging metrics per cohort (year × level). A defective harness contaminates every downstream experiment.

Theoretical framework

PyTorch is an imperative autodiff engine: operations on tensors record a computational graph (tape), and loss.backward() traverses it applying the chain rule (reverse-mode automatic differentiation). The optimizer updates parameters by a descent rule — SGD (Stochastic Gradient Descent) θ ← θ − η∇L, or Adam (Adaptive Moments) which keeps per-parameter exponential moving averages of gradient mean m and variance v with bias correction, adapting the step size: θ ← θ − η·m̂/(√v̂+ε). L

θt+1 = θt − η·∇θL(θt; Bt),    ∇θ via chain rule (autograd)

Dataset binding

ElectionDataset(canonical_long): groups by election-geography key, emits (x_tab, x_ent, x_party, x_cargo, y_share, mask_valid) where the mask excludes FLAG_CONSISTENCIA=1 groups and ambiguous coalition rows. Group batching: one full election-geography per batch preserves the Σshares=1 constraint inside the loss. P

III.3 Regularization and AI-assisted development

Dropout, weight decay, early stopping, data augmentation; AI-assisted coding practice.

Why it exists

With a small effective n — elections are rare events: ~200 presidential entity-year groups in the whole panel — regularization is the model. Week 3 translates to: how far can an MLP go without overfitting, and how does AI assistance accelerate development without compromising integrity.

Theoretical framework

Bias–variance tradeoff: expected test error decomposes into bias² + variance + irreducible noise; capacity raises variance. Regularization injects a prior penalty on complexity. L2 / weight decay adds λ‖W‖² to the loss — equivalent (for SGD) to a Gaussian prior on weights, shrinking them toward 0. Dropout (Srivastava et al. 2014) masks each hidden unit with probability p at train time and rescales at test — an ensemble of ~2^n thinned subnetworks sharing weights, discouraging co-adaptation. Early stopping halts when validation error stops improving — a form of implicit capacity control. L

Lreg = LCE + λ‖W‖² ,   Dropout: h̃ = h ⊙ Bernoulli(p) / p

Early stopping is computed on the temporal validation slice (2015–2018), never a random split: it halts when out-of-time generalization stops improving — the only honest notion of generalization for electoral series. P

Dataset binding

Reported grid: dropout ∈ {0.2, 0.3, 0.5}, λ ∈ {1e-4, 1e-3, 1e-2}, architectures {256-128} vs {128-64-32}. The final baseline configuration is reported together with its validation curve — evidence of regularization, not just a result.

III.4 Convolutional Neural Networks — spatial texture in the vote

Convolution, pooling, receptive field, weight sharing.

Why it exists

The vote has spatial texture: the PAN northern belt, southern strongholds, urban corridors. A Convolutional Neural Network (CNN) over a geographic grid learns local pattern detectors — "neighborhood with growing MORENA penetration", "opposition island" — with shared parameters that scale to thousands of municipalities.

Theoretical framework

Discrete convolution slides a kernel f over the input, computing local inner products: the same weights apply at every position (weight sharing → translation equivariance), each output unit sees only a finite receptive field. Stacking layers grows the effective receptive field — early layers see immediate neighbors, deep layers see regional context. Pooling (max/mean) adds local invariance and reduces spatial resolution. The inductive bias is locality + sharing: exactly the assumption that nearby geographies behave similarly (Tobler's first law). L

(f ∗ X)[i,j] = Σm,n f[m,n] · X[i+m, j+n] output = activation map; receptive field = neighborhood context

Dataset binding

Two possible representations: (a) a year×party×entity tensor — 1-D temporal convolution plus convolutions over parties capture cycle correlations; (b) a true geographic grid — requires rasterizing municipalities to lat/lon (hexbin or INEGI grid). Option (b) is conceptually superior but depends on external geometries; (a) is immediate on the current canonical set. P

III.5 Transfer learning — the federal panel teaches the local

Pre-training, fine-tuning, layer freezing, domain shift.

Why it exists

Federal elections have denser temporal and geographic coverage than local ones. The transfer hypothesis: representations learned on the denser federal panel transfer to the sparse panel of governorships and local deputies — analogous to ImageNet → medical imaging. P

Theoretical framework

Transfer learning exploits the idea that early network layers learn general features (Gabor-like edges in vision; here, generic "electoral response" filters) that transfer across related domains. Fine-tuning starts from pre-trained weights and updates them on the target task with a lower learning rate; freezing stops gradients below layer k. Domain shift — the gap between source and target distributions — determines whether transfer helps or hurts; a negative transfer must be reported honestly. L

θbase = argmin Lfederal ;  θlocal = argmin Llocal(θbase frozen up to layer k, new head)

Dataset binding

Source: PRESIDENTE + DIPUTADO_FEDERAL_MR (municipal and district levels, all cycles). Target: GOBERNADOR + DIPUTADO_LOCAL_MR. Entity/party embeddings are shared (common vocabulary); new heads per office. The benefit is measured against training the local model from scratch — that delta is the transfer effect. P

III.6 Autoencoders and VAEs — the electoral map as a latent manifold

Bottleneck, manifold hypothesis, ELBO, reparameterization.

Why it exists

Mexico's electoral map is approximable by few latent dimensions — "industrial north", "ancestral south", "urban center", "border". An Autoencoder (AE) forces a municipality's full electoral profile through a 2–3-dimensional bottleneck; if the manifold exists, emergent clusters should match (or refute) the literature's typology. The Variational Autoencoder (VAE, Kingma & Welling 2013) adds probabilistic structure: soft latent regions instead of hard clusters.

Theoretical framework

AE: encoder z = f(x), decoder x̂ = g(z); trained to minimize reconstruction error ‖x−x̂‖², the bottleneck forces a compressed code z capturing the dominant factors of variation. Manifold hypothesis: high-dimensional data lie near a low-dimensional manifold; the AE is a nonlinear generalization of PCA (Principal Component Analysis) that learns it. VAE: the encoder outputs a posterior q(z|x); training maximizes the ELBO (Evidence Lower Bound) — reconstruction term minus the KL divergence (Kullback–Leibler) pulling q(z|x) toward a standard-normal prior. The reparameterization trick z = μ + σ·ε, ε~N(0,I) keeps the sampling differentiable. L

ELBO = Eq(z|x)[log p(x|z)] − KL( q(z|x) ‖ N(0,I) ) x = municipality-year share vector; z = latent electoral profile

Dataset binding

x = vector of a municipality's party shares in one cycle (≈10–15 relevant parties, rest folded into "other"). AE and VAE trained over all valid municipality-years; the 2-D latent space is projected to a map and compared with documented regions (§I.5). Structural bonus: the decoder reconstructs plausible elections → municipalities with high reconstruction error are system outliers — candidates for forensic capstone C4. P
