Part VII

Model rationale and pedagogical cards

Every architecture used in this thesis appears below as a model card: a pedagogical summary that answers, before any code is written, why the model was chosen, what problem it solves, what it assumes, how it will be trained, how it will be evaluated, how its outputs should be read in an electoral context, and what can go wrong. The first use of every acronym inside each card is expanded. These cards are the bridge between the course syllabus and the notebooks of Sprints 1–5. SYLLABUS-CONFIRMED

Card 1

Multi-Layer Perceptron (MLP) — tabular baseline

Selection rationale. An election, to first approximation, is a nonlinear function of a fixed vector of covariates: past shares, macroeconomics, marginalization, incumbency, and structural dummies. When there is no explicit ordering in the input, the simplest universal approximator is the honest baseline. The MLP's only inductive bias is smoothness and compositionality of functions; it does not invent spatial or temporal structure that may not exist.

What it does. An MLP maps an input vector x ∈ R^F through one or more hidden layers h = σ(Wx+b) to a target ŷ. With a softmax output it produces a probability distribution over parties; with a linear output it predicts a scalar such as turnout. The Universal Approximation Theorem (Cybenko 1989; Hornik 1991) guarantees that a wide enough single-hidden-layer network can approximate any continuous function on a compact set, while depth makes that approximation efficient (Eldan & Shamir 2016).

Core concepts, expanded. A neuron computes an affine transformation w·x + b followed by a nonlinearity σ. ReLU (Rectified Linear Unit) returns max(0,z); it is computationally cheap but can "die" when the input is always negative. GELU (Gaussian Error Linear Unit) returns z·Φ(z), where Φ is the CDF (Cumulative Distribution Function) of the standard normal distribution — a smooth probabilistic gating used in Transformers. Softmax converts a real vector into a probability vector by exponentiating and normalizing. Cross-Entropy (CE) measures the disagreement between the predicted distribution and the true one; it is the Maximum Likelihood Estimation (MLE) loss for a categorical model. Backpropagation applies the chain rule of calculus layer by layer to compute how each weight affects the loss, so gradient descent can update it.

Inputs. One row per election-geography unit: lagged party shares, lagged macroeconomic and remittance features, structural dummies, and learned embeddings for entity, party and office.

Outputs. Party-share vector (softmax, sums to 1), scalar turnout, and a winner class.

Training procedure. Minimize CE plus L2 weight decay using SGD (Stochastic Gradient Descent) or Adam (Adaptive Moment Estimation, which keeps exponential moving averages of gradient mean and variance and rescales the learning rate per parameter). Early stopping is monitored on the temporal validation slice (2015–2018), never on the test set. The scaler is fit only on the training split to avoid leakage.

Evaluation. Mean Absolute Error (MAE) on party shares, top-1 winner accuracy, Brier score (probabilistic calibration of the winner), and Expected Calibration Error (ECE). The mandatory comparison is against a persistence baseline ("predict the previous election's shares").

Electoral interpretation. The MLP answers the research question: how much signal lives in the table alone, with no explicit time or space model? If the MLP cannot beat persistence, more complex models must justify every additional parameter.

Assumptions. (i) Conditional on the engineered features, observations are exchangeable — the model has no memory and no geography. (ii) The target shares lie in a probability simplex. (iii) Past votes and macro variables contain enough information to forecast the next election.

Limitations. It cannot exploit sequence, spatial adjacency, or text. It is vulnerable to overfitting when n is small (only ~6–8 presidential cycles per unit), so regularization is essential. Coalition labels such as PAN_PRI_PRD are treated as atomic tokens unless a separate redistribution sensitivity is run.

Card 2

Convolutional Neural Network (CNN) — spatial texture

Selection rationale. The vote has local spatial texture: northern manufacturing belts, southern indigenous strongholds, urban corridors. A CNN learns local pattern detectors with shared parameters, so the same kernel that detects "opposition island" in one region applies everywhere. It is appropriate when the input can be arranged as a grid or a sequence with local neighborhoods.

What it does. A convolution slides a small kernel across the input and computes local dot products. Weight sharing means the same kernel is applied at every position; translation equivariance means a pattern is detected wherever it appears. Stacking layers grows the receptive field, so deep units see regional context. Pooling (max or mean) makes the representation locally invariant and reduces resolution.

Inputs. Two options are declared: (a) a year × party × entity tensor for federal-level analysis; (b) a true geographic grid of municipalities (requires INEGI geometry or a hexbin raster). Option (a) is a correlation detector, not a spatial one; option (b) is the faithful spatial operator.

Outputs. Learned feature maps, followed by a dense head for shares or winner.

Training procedure. Cross-entropy on party shares, with dropout after the global-pooling layer. The kernel size is chosen so the receptive field covers a few neighboring units; padding preserves border information.

Evaluation. MAE and winner accuracy versus the MLP baseline on the identical split; qualitative inspection of the first-layer kernels as spatial filters.

Electoral interpretation. The CNN tests whether local geographic texture adds predictive signal beyond tabular features. If it does not, geography may be better captured by an explicit graph (GNN) or by entity embeddings.

Assumptions. (i) Nearby positions in the input are semantically related (Tobler's first law). (ii) The input grid is topologically meaningful; a year×party arrangement is not a true map and must not be reported as spatial.

Limitations. Edge effects make Baja California and Yucatán boundaries special. Irregular municipal borders do not fit a rectangular grid; the CNN is therefore a precursor to the GNN, not its substitute.

Card 3

Autoencoder (AE) / Variational Autoencoder (VAE) — latent electoral profiles

Selection rationale. There are no official labels for "electoral regions" of Mexico beyond coarse geographic names. An unsupervised bottleneck learns a low-dimensional representation of a municipality's full voting profile, revealing clusters that may match — or refute — the literature's typology (north, south, center, border). The VAE adds a probabilistic latent space suitable for simulation and anomaly detection.

What it does. An AE (Autoencoder) has an encoder z = f(x) and a decoder x̂ = g(z); it minimizes reconstruction error ‖x − x̂‖². The bottleneck forces a compressed code. A VAE (Variational Autoencoder) makes the encoder output a distribution q(z|x) instead of a single point; training maximizes the ELBO (Evidence Lower Bound), which is the expected reconstruction log-likelihood minus the KL divergence (Kullback–Leibler divergence) from the posterior to a standard-normal prior. The reparameterization trick z = μ + σ·ε, with ε ~ N(0,I), keeps sampling differentiable.

Inputs. Municipality-year party-share vectors from presidential elections, with small parties folded into an "other" category.

Outputs. A 2-D or 3-D latent coordinate per municipality-year; a reconstruction error that flags outliers for the forensic capstone.

Training procedure. Adam optimizer on reconstruction MSE for the AE, and on the negative ELBO for the VAE. β-VAE variants weight the KL term to encourage disentangled latent axes. Multiple random seeds test stability.

Evaluation. Reconstruction MAE, silhouette of latent clusters against known regions, and seed-stability of the resulting map.

Electoral interpretation. Latent dimensions may correspond to axes such as "north–south industrial divide" or "rural–urban". Municipalities with high reconstruction error are structurally anomalous — candidates for the anomaly-forensics capstone, not automatically fraudulent.

Assumptions. (i) High-dimensional vote profiles lie near a low-dimensional manifold (manifold hypothesis). (ii) The latent axes are stable enough to be meaningful across cycles. (iii) Mixing multiple years in one space does not confound historical drift with geography.

Limitations. Latent dimensions arrive unlabeled; naming them requires manual correlation with covariates. VAEs may collapse if the KL term dominates; monitoring reconstructions is mandatory.

Card 4

Transformer — self-attention over electoral history

Selection rationale. A recurrent network must propagate memory through every cycle between the present and a distant past; a Transformer accesses any past cycle directly. This makes it a natural tool when the research question is interpretive as well as predictive: which past elections drive the current forecast?

What it does. A Transformer encoder builds a sequence representation using self-attention. Each position emits a query Q, a key K, and a value V; the output is a weighted sum of values, where the weight measures how much the query "attends" to each key. The dot products are scaled by √d_k so that softmax gradients do not vanish when dimension is large. Multi-Head Attention (MHA) runs several attention functions in parallel, allowing different heads to focus on different temporal regimes. Layer normalization stabilizes activations; residual connections let the network preserve raw features. Positional encoding injects order, which is implemented here as a learned or continuous ANIO embedding because electoral calendars are irregular. Causal masking blocks attention to future positions, preserving temporal causality.

Inputs. A sequence of cycle embeddings per unit: past party shares, lagged macroeconomics, structural indicators, and a time-stamp embedding.

Outputs. Next-cycle party shares, winner probabilities, and an attention matrix per head for interpretability.

Training procedure. Cross-entropy on the next cycle, with the same temporal split as the LSTM. Small d, few layers, and high dropout are used because n is small.

Evaluation. Same metrics as LSTM (MAE, winner accuracy, Brier). Attention maps are reported as a paper figure and treated as evidence, not as proof of importance.

Electoral interpretation. If attention concentrates on the immediately previous cycle, the system behaves like a smart persistence model. If it spreads across a whole sexenio, the model has learned longer-term regime dynamics.

Assumptions. (i) Past cycles are informative and the relevant ones can be identified by query-key similarity. (ii) Sequence length is small enough (T≈5–10) that quadratic attention cost is acceptable. (iii) The positional encoding captures true calendar distance.

Limitations. With only a handful of cycles per unit, Transformers overfit easily; the fair comparison is against the LSTM on the identical split. State-space models (Card 6) provide an efficiency alternative.

Card 5

Long Short-Term Memory (LSTM) / Gated Recurrent Unit (GRU) — electoral memory

Selection rationale. Elections have memory: incumbent punishment, party stronghold inertia, sexenio effects. A recurrent model is the appropriate neural temporal baseline because it is expressive enough for these dynamics and small enough to fit our short, irregular panels.

What it does. A plain RNN (Recurrent Neural Network) updates a hidden state h_t = f(h_{t−1}, x_t), but gradients vanish over long spans. An LSTM adds a cell state c_t and three gates: an input gate decides what to write, a forget gate decides what to keep, and an output gate decides what to emit. A GRU merges the cell and hidden state into an update gate and a reset gate, using fewer parameters.

Inputs. Same cycle sequence as the Transformer (Card 4).

Outputs. Next-cycle party shares and winner class.

Training procedure. Minimize next-cycle CE with teacher forcing during training: the true previous output is fed as the next decoder input. Bidirectionality is forbidden because it would attend to future cycles and leak information.

Evaluation. MAE, winner accuracy, and a direct head-to-head comparison with the Transformer on the same split.

Electoral interpretation. The forget-gate values can be inspected to see whether the model treats the previous election or the previous sexenio as the dominant memory. The LSTM is the honest recurrent counterpart to the Transformer; the delta between them is a design datum.

Assumptions. (i) The relevant dynamics can be summarized by a hidden state vector. (ii) Causality is respected (no future information). (iii) There are enough sequences to learn the gates reliably.

Limitations. For local elections, sequences may contain only 1–3 cycles per unit. Pooling by entity or strong regularization is required; invented history is not allowed.

Card 6

State-Space Model (SSM) — efficient sequence alternative

Selection rationale. Transformers cost O(T²) in sequence length. For our short panels the absolute cost is modest, but comparing an SSM such as Mamba or TSMixer documents whether linear-time recurrence sacrifices accuracy for speed — a design datum, not an assumption.

What it does. A linear SSM (State-Space Model) defines a continuous or discrete dynamical system h_t = A·h_{t−1} + B·x_t, y_t = C·h_t. The state is updated in O(1) per step, so the whole sequence is processed in O(T). Selective variants such as Mamba make A, B, and C input-dependent, recovering content-aware behavior without attention.

Inputs. Identical cycle sequence to Cards 4 and 5.

Outputs. Next-cycle party shares and winner class.

Training procedure. Same objective as the LSTM/Transformer; compare wall-clock time and parameter count alongside predictive error.

Evaluation. MAE, winner accuracy, training time per epoch, and number of parameters versus the Transformer.

Electoral interpretation. If the SSM matches the Transformer, the extra quadratic cost of attention is unnecessary for this dataset and the simpler recurrent structure is preferred.

Assumptions. (i) The target dynamics are approximately linear in a learned latent state. (ii) Input-dependent transitions add enough flexibility for electoral memory.

Limitations. SSM libraries for time-series are less mature than Transformers; if implementation does not converge, the comparison is reported as a conceptual note with the attempted configuration.

Card 7

Graph Neural Network (GNN) / Graph Convolutional Network (GCN) / Graph Attention Network (GAT) — real geography

Selection rationale. A map is not a grid. Municipal borders are irregular and the relationship that matters for voting is contiguity and socioeconomic similarity. A GNN models municipalities as nodes and geographic or feature-based edges, letting information diffuse across the true topology. It replaces the CNN's artificial grid with a faithful graph operator.

What it does. A GNN (Graph Neural Network) updates each node's representation by aggregating messages from its neighbors. A GCN (Graph Convolutional Network) averages neighbor embeddings according to the normalized adjacency matrix. A GraphSAGE network samples and aggregates a fixed-size neighborhood. A GAT (Graph Attention Network) learns how much weight to give each neighbor, so some borders matter more than others. All variants share the core idea: similar connected units should have similar representations.

Inputs. Municipal graph: nodes = municipalities; edges = INEGI contiguity (or a documented k-NN fallback based on centroid distance or feature similarity). Node features = lagged shares, macro lag, VAE latent profile (Card 3).

Outputs. Updated node embeddings and predictions for next-cycle share/winner.

Training procedure. Semi-supervised: train on labeled election nodes, propagate through the graph via message passing. Use the same temporal split, with edges present only among units observed in the training period.

Evaluation. MAE and winner accuracy on local elections, compared with MLP and CNN. Ablation: GNN with contiguity edges vs. k-NN feature-similarity edges.

Electoral interpretation. The GNN tests whether geographic spillovers exist between neighboring municipalities. If the model improves, spatial diffusion is a real source of information; if not, geography is already captured by entity-level dummies.

Assumptions. (i) Adjacency is a meaningful proxy for information or behavioral diffusion. (ii) The graph is static or evolves slowly relative to electoral cycles. (iii) Boundary cases (islands, borders with other countries, disconnected municipalities) are handled explicitly.

Limitations. Building the adjacency requires official INEGI geometries; the fallback k-NN graph is an approximation and must be labeled as such. Edge definition directly influences results.

Card 8

Generative models — simulation and counterfactual illustration

Selection rationale. Generative models are pedagogically valuable for asking "what if" questions: what would 2024 look like with 2018 inflation? They are not used as predictions because the conditional distributions are not validated causally.

What it does. A GAN (Generative Adversarial Network) pits a generator G against a discriminator D in a minimax game; at equilibrium, G produces samples that D cannot distinguish from real data. A VAE decoder can also generate samples by feeding new latent points. Diffusion models gradually denoise random noise toward a data sample.

Inputs. Latent points or noise; conditional covariates such as a synthetic macro scenario.

Outputs. Synthetic municipality-year vote profiles.

Training procedure. Train the VAE (Card 3) first; use its decoder to generate profiles under perturbed macro inputs.

Evaluation. Visual inspection of latent traversals and distributional checks (party-share marginals, turnout). No predictive metrics are reported as findings.

Electoral interpretation. These outputs are explicitly labeled ILLUSTRATIVE. They help communicate uncertainty and sensitivity, not to claim a forecast.

Assumptions. (i) The latent distribution generalizes to unseen counterfactual conditions. (ii) The generative process is not causal.

Limitations. Without causal identification, generated profiles are speculations. They may inherit historical biases and produce implausible coalitions.

Card 9

Bag-of-Words (BoW) / Term Frequency–Inverse Document Frequency (TF-IDF) — textual floor

Selection rationale. Before using deep text models we must know whether simple word frequencies predict anything. BoW plus TF-IDF is transparent, fast, and interpretable; it sets the floor every neural method must beat or justify.

What it does. BoW represents a document as a vector of word counts, discarding order. TF-IDF (Term Frequency–Inverse Document Frequency) reweights each word by its rarity across the corpus: common words are downweighted, distinctive words are upweighted. The formula is TF-IDF(w,d) = count(w,d) · log(N / df_w), where N is the number of documents and df_w is the number of documents containing word w.

Inputs. Text of presidential interventions in a 90-day pre-election window, aggregated per entity (locals) or nationally (federals).

Outputs. Sparse feature vector per window, plus a linear or logistic prediction head for incumbent share or alternation.

Training procedure. Build the vocabulary on the temporal training set only; then vectorize all splits. A regularized linear model (logistic or ridge) serves as the text baseline.

Evaluation. MAE on incumbent share and Area Under the Receiver Operating Characteristic Curve (AUC) for alternation; top-weighted terms for interpretability.

Electoral interpretation. BoW tells us whether the frequency of words such as "seguridad", "empleo", or "corrupción" in the weeks before an election carries signal. If it does not, the extra capacity of LSTMs and BERT may be wasted.

Assumptions. (i) Word order does not matter much for this task. (ii) A fixed pre-election window captures the relevant discourse. (iii) TF-IDF vocabulary is stable across sexenios.

Limitations. Negation, irony, and context are lost. Political acronyms and neologisms may be split by a generic tokenizer.

Card 10

Text RNN / LSTM over political discourse

Selection rationale. If word order matters — for example, "no vamos a permitir" versus "vamos a permitir" — a recurrent text model should improve over BoW. The text RNN quantifies how much lexical order adds in this domain.

What it does. Each token is embedded into a dense vector; an LSTM or GRU reads the sequence and produces a final hidden state that summarizes the discourse. A dense head maps that state to the target.

Inputs. Tokenized intervention or aggregated daily discourse, aligned to the pre-election window.

Outputs. Incumbent share, alternation probability, or stance class.

Training procedure. Pre-trained or randomly initialized token embeddings; LSTM over the sequence; cross-entropy or MSE. Dropout on the recurrent output and the embedding layer.

Evaluation. Same as BoW; the head-to-head delta measures the value of sequence.

Electoral interpretation. A significant improvement means that phrasing, negation, and narrative structure carry information beyond mere word counts.

Assumptions. (i) The relevant signal is in the order of words within an intervention. (ii) The corpus is large enough to learn meaningful token embeddings.

Limitations. Long interventions and rare tokens make training unstable. The model has no access to broader context beyond the single input sequence.

Card 11

Byte-Pair Encoding (BPE) tokenizer — domain morphology

Selection rationale. Mexican political Spanish contains acronyms and neologisms (INE, MORENA, IMSS, "chairos", "fifís", "mañanera") that a generic tokenizer may split incorrectly. Training a domain-specific tokenizer reduces the out-of-vocabulary rate and improves every downstream text model.

What it does. BPE (Byte-Pair Encoding) starts from characters and greedily merges the most frequent adjacent pair until a vocabulary of size B is reached. Frequent words become single tokens; rare words decompose into subwords. By construction, OOV (Out-Of-Vocabulary) tokens disappear, because any word can be spelled from subwords.

Inputs. The full mañaneras corpus.

Outputs. A vocabulary file and tokenization statistics: OOV rate against a generic Spanish tokenizer, mean tokens per word, acronym coverage.

Training procedure. Count pairs, merge, repeat; evaluate on held-out political interventions.

Evaluation. OOV rate, tokenization stability, and downstream task improvement (LSTM or BERT fine-tuning).

Electoral interpretation. A specialized tokenizer is a measurable investment: if political acronyms are not treated as atomic units, the model misses a core feature of Mexican discourse.

Assumptions. (i) The corpus is large and representative enough to learn stable merges. (ii) The vocabulary size B balances compactness and coverage.

Limitations. BPE is greedy and deterministic; it cannot handle new acronyms after training. Comparison with a pre-trained Spanish tokenizer is mandatory.

Card 12

N-gram language models — rhetorical regime change

Selection rationale. N-grams are the simplest language model. Comparing cross-sexenio perplexity quantifies how much the presidential vocabulary changed from one administration to the next — a proxy for rhetorical regime change.

What it does. An n-gram model estimates the probability of a word given the previous n−1 words, P(w_t | w_{t−n+1} … w_{t−1}), from smoothed counts. Perplexity is the exponential of the average negative log-probability: exp(−(1/N) Σ log P(w_t)). Lower perplexity means the model finds the text more predictable.

Inputs. Tokenized corpus split by sexenio.

Outputs. Per-sexenio perplexity and a cross-sexenio perplexity matrix; derived feature drift_retorico_sexenio.

Training procedure. Estimate n-gram counts (n=2,3,4) with Kneser–Ney or Laplace smoothing on one sexenio; evaluate perplexity on another.

Evaluation. Cross-perplexity heatmap; stability against random train/test splits.

Electoral interpretation. If a 2024 model trained on 2018 discourse has high perplexity, the rhetorical regime has shifted. This is a covariate of possible electoral realignment.

Assumptions. (i) Vocabulary and style evolve slowly enough to model per sexenio. (ii) Predictability correlates with rhetorical continuity.

Limitations. N-grams ignore long-range syntax and semantics. Perplexity is not a causal predictor.

Card 13

Word embeddings — semantic geometry of the political lexicon

Selection rationale. Embeddings turn political concepts into vectors such that related words are close and analogies are arithmetic. They let us measure semantic drift across sexenios (e.g., does "MORENA" move toward where "PRD" used to be?).

What it does. Word2Vec skip-gram learns vectors by predicting the context words around a target word; words that share contexts end up close in the embedding space. GloVe (Global Vectors) factorizes the log co-occurrence matrix instead. The geometry supports analogies such as v_rey − v_hombre + v_mujer ≈ v_reina.

Inputs. Tokenized mañaneras corpus, possibly split by sexenio.

Outputs. Dense vectors (e.g., 100-dimensional) for each word, and a t-SNE/UMAP map for visualization.

Training procedure. Train skip-gram with negative sampling or GloVe on the corpus; evaluate on word-similarity tasks for key political terms.

Evaluation. Cosine-similarity rankings of known related terms; visualization quality; downstream classification improvement over BoW.

Electoral interpretation. Embedding drift tracks how the political lexicon reorganizes between administrations. A party embedding that moves closer to "pobreza" or "transformación" signals a repositioning in the agenda.

Assumptions. (i) Context predicts meaning well enough in political speech. (ii) The corpus is large enough to learn stable vectors. (iii) Analogies in the political domain are approximately linear.

Limitations. Embeddings are static and do not handle polysemy or context; a pre-trained contextual encoder (BETO, Card 17) addresses this.

Card 14

t-SNE / UMAP — visualizing high-dimensional semantics

Selection rationale. Human readers cannot inspect 100-dimensional vectors directly. Dimensionality reduction maps them to 2-D for visualization, with the caveat that global distances are distorted.

What it does. t-SNE (t-distributed Stochastic Neighbor Embedding) minimizes the KL divergence between pairwise similarity distributions in the original high-dimensional space and the 2-D map. UMAP (Uniform Manifold Approximation and Projection) assumes the data lie on a manifold and preserves both local and more global structure, often faster than t-SNE.

Inputs. Word embeddings, municipality latent profiles (Card 3), or BETO sentence embeddings.

Outputs. 2-D scatter plots colored by word type, party, sexenio, or geographic region.

Training procedure. Run t-SNE or UMAP with multiple perplexity/neighbor settings; report the most stable one.

Evaluation. Visual inspection and nearest-neighbor preservation metrics.

Electoral interpretation. Clusters in the map reveal conceptual neighborhoods — for example, economic terms, security terms, or regional references. The map is a communication tool, not a quantitative distance metric.

Assumptions. (i) Local neighborhoods in high-D are meaningful. (ii) A 2-D embedding preserves enough structure to be useful.

Limitations. Global distances in t-SNE/UMAP are not interpretable. Different hyperparameters produce different layouts; stability checks are required.

Card 15

Latent Dirichlet Allocation (LDA) — the presidential agenda as a variable

Selection rationale. Agenda-setting theory says that what the government talks about influences what citizens think about. LDA turns the mañaneras corpus into a time series of topic prevalences that can be merged with the electoral data as a structural covariate.

What it does. LDA is a generative probabilistic topic model. Each document draws a topic mixture θ_d ~ Dirichlet(α); each topic is a word distribution φ_k ~ Dirichlet(β); each observed word picks a topic and then a word from that topic. Inference recovers the θ and φ distributions. Topic quality is measured by C_v coherence, which compares the semantic similarity of a topic's top words.

Inputs. Daily or weekly bags of words from the mañaneras corpus.

Outputs. K topic-word distributions and a time series of topic prevalence share_topic_k per week.

Training procedure. Fit LDA for K ∈ {10, 20, 30, 50} on the training corpus; select K by C_v coherence; apply the trained model to all windows.

Evaluation. C_v coherence, manual topic labels, and predictive correlation with incumbent support or turnout.

Electoral interpretation. A rising prevalence of security discourse before a state election may depress turnout or favor the opposition; the topic-share series makes that hypothesis testable.

Assumptions. (i) Documents are mixtures of a small number of topics. (ii) The Dirichlet prior is appropriate for discourse. (iii) Topics are stable across the training period.

Limitations. LDA is a bag-of-words model: it ignores word order and context. The number of topics K must be chosen by the analyst.

Card 16

Structural Topic Model (STM) — topics conditioned on context

Selection rationale. LDA ignores document metadata. STM makes topic prevalence a function of covariates (sexenio, pre-electoral quarter, inflation), yielding regression coefficients that can be interpreted substantively: for example, "one extra inflation point corresponds to a Δ increase in economy-topic discourse."

What it does. STM generalizes LDA by drawing the topic-mixture parameter from a logistic-normal distribution whose mean is a linear regression Γ·x_d on document covariates. The Γ coefficients are directly interpretable. Topic content can also depend on covariates.

Inputs. Same corpus as LDA plus document-level covariates: year, sexenio, pre-electoral indicator, and contemporaneous macro variables.

Outputs. Topic prevalence series and a table of Γ coefficients with confidence intervals.

Training procedure. Fit the STM package (R) via rpy2 or a separate documented script; inspect convergence diagnostics.

Evaluation. Coherence, coefficient significance, and comparison with LDA on a held-out prediction task.

Electoral interpretation. STM turns the agenda from a black-box cluster into a measurable response to economic and political context. It produces coefficients, not just clusters.

Assumptions. (i) Topic prevalence is smoothly related to covariates. (ii) The logistic-normal link is appropriate. (iii) Covariates are not collinear.

Limitations. STM is more computationally demanding than LDA and requires careful covariate construction. It is fit in R, so the notebook must document the R–Python bridge.

Card 17

Named Entity Recognition (NER) and stance classification — territorial attention

Selection rationale. Two electoral questions require text understanding: (a) what is the president's tone toward opposition, economy, and security? and (b) which states and municipalities does the president mention? The latter is a unique feature enabled by the mañaneras corpus: presidential territorial attention.

What it does. NER assigns each token a BIO tag: B-X marks the beginning of an entity of type X, I-X its inside, and O means outside any entity. Entity types are typically PER (person), ORG (organization), LOC (location), and GPE (geopolitical entity). Stance classification assigns a document or span to a label such as positive, negative, neutral, or combative toward a target.

Inputs. Sentence-level or intervention-level text from the mañaneras corpus.

Outputs. Lists of normalized entity mentions per date and a stance label per relevant span; weekly aggregation atencion_presidencial_ent.

Training procedure. Fine-tune a Spanish/multilingual BERT-NER model on a labeled sample, or use an off-the-shelf Spanish NER model with a gazetteer that maps mentions to the canonical entity key. Stance requires an annotated sample (n≥500) with inter-annotator agreement or LLM-assisted validation.

Evaluation. Entity-level F1 for NER; macro-F1 for stance. Manual error analysis on the most frequent entities.

Electoral interpretation. If the president mentions a state more frequently in the months before its gubernatorial election, attention itself becomes a covariate. Stance tracks the tonal climate around key issues.

Assumptions. (i) Entity mentions can be normalized reliably to electoral geography. (ii) Stance labels are stable across annotators. (iii) Attention is measured by mention frequency, which is a coarse proxy.

Limitations. NER models may miss colloquial place names and abbreviations. Stance annotation is subjective and must be reported with agreement metrics.

Card 18

Conditional Random Field (CRF) — interpretable sequence baseline

Selection rationale. A CRF is the classical, interpretable baseline for NER. Before declaring that a deep Transformer NER is necessary, we measure whether a linear-chain CRF with hand-crafted features already solves most of the problem.

What it does. A CRF is a discriminative undirected graphical model over a sequence. It models P(y|x) ∝ exp(Σ_t [s(y_t,x,t) + A_{y_{t−1},y_t}]), where s scores the emission features of tag y_t at position t and A is the learned transition matrix that encodes which tags may follow which. Decoding uses the Viterbi algorithm.

Inputs. Tokens with orthographic features (capitalization, prefixes, suffixes, ±2 word context).

Outputs. BIO tag sequence and the interpretable transition matrix.

Training procedure. Train sklearn-crfsuite on a labeled NER sample; tune regularization on a development set.

Evaluation. Entity-level F1 against the same test set used for the Transformer NER.

Electoral interpretation. The transition matrix itself is a deliverable: it shows, for example, that a location tag is unlikely to follow a person tag. This transparency is the reason the CRF is retained even after a deep model is trained.

Assumptions. (i) Tag transitions are the main source of structure. (ii) Local orthographic features are sufficient to identify entities.

Limitations. CRFs do not share parameters across words and cannot leverage subword or contextual semantics; hence they are expected to underperform BETO-NER on rare mentions.

Card 19

BETO / BERT — contextual Spanish encoder for fusion

Selection rationale. BETO is the Spanish BERT model. It produces contextual embeddings that capture word meaning in context and subword structure, solving many of the limitations of static embeddings and bag-of-words models. Its [CLS] token or mean-pooled sentence embedding feeds the multimodal fusion in Part V.

What it does. BERT (Bidirectional Encoder Representations from Transformers) is a bidirectional Transformer encoder pre-trained on Spanish text with MLM (Masked Language Modeling): random tokens are hidden and the model learns to predict them. BETO is the Spanish adaptation. Fine-tuning adds a task-specific head on top of the pre-trained body.

Inputs. Intervention text or aggregated daily discourse chunks.

Outputs. A 768-dimensional vector per input, optionally a classification score for stance or NER.

Training procedure. Fine-tune BETO on stance classification and/or NER with a small learning rate; freeze lower layers if overfitting. Persist embeddings to texto_emb.parquet for fusion.

Evaluation. Downstream task F1; ablation of domain fine-tuning versus generic BETO pool; fusion improvement in Part V.

Electoral interpretation. BETO embeddings encode the contextual meaning of the discourse at each date. They are the textual branch's contribution to the multimodal model and the final input for textual nowcasting.

Assumptions. (i) Spanish political discourse is close enough to the BETO pre-training distribution. (ii) Fine-tuning data are representative and not leaked.

Limitations. BERT is computationally expensive; embeddings are computed once and reused. It may struggle with highly colloquial political jargon absent from pre-training.

Card 20

Late-fusion multimodal model — combining every channel

Selection rationale. Mexican elections are a multimodal problem: votes (tabular), history (temporal), geography (spatial), and discourse (text). Late fusion keeps each modality's encoder independent and auditable, then learns only the combination. This avoids forcing incompatible geometries (vectors, sequences, graphs, text) into a single early representation and makes ablations clean.

What it does. Each branch (MLP tabular, LSTM temporal, GNN spatial, BETO textual) is trained on its own task and then frozen. Each emits a fixed-length embedding. These are concatenated with election and geography embeddings and fed into a small fusion MLP. The fusion head predicts shares, winner, and turnout.

Inputs. For each target election: tabular features, the unit's past cycle sequence, the municipal graph context, and the pre-election textual representation.

Outputs. Party shares (softmax), winner class, scalar turnout, and uncertainty via Monte Carlo dropout or an ensemble.

Training procedure. Train each branch separately; freeze; train the fusion head with the same temporal split. Then run mandatory ablations: tabular only, +temporal, +spatial, +text, full. Report each channel's marginal Δ over the tabular baseline.

Evaluation. Full metric suite (MAE, winner accuracy, Brier, ECE) per ablation. The key result is not the full model's absolute score but the incremental value of each channel.

Electoral interpretation. The fusion answers the thesis question: how much does each mode of information — past votes, time, geography, presidential discourse — add to the prediction of Mexican elections? A negative ablation is also a finding.

Assumptions. (i) Channels provide complementary, not redundant, information. (ii) Freezing branches preserves their individual meaning. (iii) The fusion head is small enough to avoid overfitting the limited panel.

Limitations. The model is only as good as the weakest link; missing text data or an approximate adjacency graph limit the full fusion. Causal interpretation is forbidden.

Card 21

Capstones — C1 GNN, C2 multimodal, C3 turnout, C4 anomaly forensics, C5 textual nowcasting

C1 — Municipal GNN. Use Card 7 to predict local elections. Tests whether geographic diffusion matters at the municipal level. Requires INEGI adjacency or the documented k-NN fallback.

C2 — Multimodal late fusion. Use Card 20 to combine all validated branches. This is the central thesis experiment.

C3 — Turnout forecasting. Predict PARTICIPACION with Cards 1 and 5. Turnout is continuous and avoids the complexity of compositional shares, so it is the first end-to-end sprint.

C4 — Electoral-anomaly forensics. Use reconstruction errors from Card 3 and residuals from Cards 1 and 5 plus FLAG_CONSISTENCIA to flag statistical anomalies. Inspired by Cantú (2014), but reported only as anomalies, never as legal fraud.

C5 — Textual nowcasting. Use Cards 9–19 with only pre-election text and recent macro to predict outcomes. Measures whether discourse carries anticipatory signal, with strict publication-date leakage control.
