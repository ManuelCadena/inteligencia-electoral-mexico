# Resultados

Carpeta para guardar figuras, modelos entrenados, métricas y reportes generados durante la investigación.

```
results/
├── figures/        # Gráficas de EDA, mapas, curvas de entrenamiento
├── models/         # Checkpoints (.keras, .pt, .pkl)
├── metrics/        # JSON/CSV con métricas de evaluación
└── reports/        # Reportes en Markdown o HTML
```

No versionar archivos grandes en Git; preferir Google Drive, HuggingFace Hub o Zenodo.
